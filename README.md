## 📖 عن المشروع

**ElnegmCrypt** هو تطبيق ويب متكامل لتشفير وفك تشفير الرسائل النصية، مصمم بأسلوب السايبر بنك (Cyberpunk) مع تأثيرات بصرية مذهلة. يسمح للمستخدمين بتشفير رسائلهم بأربع طرق مختلفة ومشاركتها بأمان مع الآخرين.

### ✨ المميزات

- 🔐 **تشفير بأربع طرق**: Base64، قيصر (Caesar)، عكس النص، ثنائي (Binary)
- 🔓 **فك التشفير** بنفس الطرق المستخدمة في التشفير
- 📜 **سجل محلي** للعمليات باستخدام LocalStorage
- 🎨 **تصميم سايبر بنك** بالكامل بدون أي صور خارجية
- 🌟 **تأثيرات بصرية**:
  - خلفية Matrix Rain متحركة
  - جسيمات (Particles) متحركة
  - تأثيرات نيون (Neon Glow)
  - تأثير طرفية (Terminal)
  - تأثير كتابة (Typing Effect)
- 📱 **تصميم متجاوب** مع جميع أحجام الشاشات
- 🎯 **سهولة الاستخدام** مع واجهة بديهية
- 📊 **لوحة تحكم إدارية** لعرض الإحصائيات
